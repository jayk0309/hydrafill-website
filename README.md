HydraFill — Hydration Tracker 💧

A hydration tracking mobile application designed to help users build healthier hydration habits through daily goals, progress tracking, reminders, and personalised insights.

✨ Features

* Daily Hydration Tracking: Log drinks and monitor daily water intake.
* Personalised Goals: Set hydration targets and track progress.
* Progress Visualisation: Review hydration history and daily achievements.
* Smart Reminders: Receive reminders to help maintain consistent hydration habits.
* Insights and History: Explore past hydration activity and progress.
* Challenges and Badges: Stay motivated through milestones and achievements.
* Health Integrations: Support for compatible Apple Health and Android Health Connect integrations, where available.

Ensure each listed feature matches the currently released app.

🛠️ Technology Stack

The mobile application is built with Flutter and Dart, with technologies including:

* State Management: Riverpod
* Backend and Data: Supabase
* Authentication: Supabase Auth
* Offline Support: Local logging and synchronisation
* Health Integrations: Apple Health and Android Health Connect
